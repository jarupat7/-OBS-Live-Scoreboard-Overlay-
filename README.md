# 🏸 Badminton Broadcast & Tournament Management System
ระบบจัดการคะแนนแข่งขันแบดมินตันสำหรับถ่ายทอดสด (OBS Studio) + จอใหญ่ข้างสนาม (Courtside Big Screen) + หน้าจอกรรมการบนมือถือ (Mobile Referee Controller) โดยใช้ **Google Sheets เป็นฐานข้อมูล Real-time** และโฮสต์บน **GitHub Pages** (ฟรี 100%)

---

## 🌟 ฟังก์ชันและจุดเด่นของระบบ

1. **📥 ระบบดึงข้อมูลนักกีฬาและตารางแข่งจาก Google Sheet ภายนอกอัตโนมัติ (Auto-Sync Schedule)**:
   * สามารถใส่ลิงก์ Google Sheet รายชื่อนักกีฬา/ตารางแข่ง (เช่น `https://docs.google.com/spreadsheets/d/1kQLMW_jvr7OKscZ_Pq-leitq-P6n4DCT1vDywM4pADA/...`)
   * ระบุแท็บข้อมูล (เช่น แท็บ `Data`)
   * **กรองเฉพาะคอร์ทที่ต้องการถ่ายทอดสดได้** เช่น ใส่ `คอร์ท 9` หรือ `9` หรือ `A1` ระบบจะดึงเฉพาะคู่ที่แข่งในคอร์ทนั้นเข้าสู่ตารางแข่งให้อัตโนมัติ (หรือเว้นว่างเพื่อดึงทุกคอร์ท)
2. **🏸 เลือกกติกาแข่งขันแบบ 15 แต้ม หรือ 21 แต้มได้ (Rally Point 15/21 with Deuce)**:
   * **กติกา 21 แต้ม**: ดิวซ์ที่ 20-20 ชนะห่าง 2 แต้ม หรือแต้มสูงสุด 30 แต้มชนะทันที
   * **กติกา 15 แต้ม**: ดิวซ์ที่ 14-14 ชนะห่าง 2 แต้ม หรือแต้มสูงสุด 21 แต้มชนะทันที
   * กรรมการสามารถกดสลับโหมด 15/21 ได้ทันทีจากหน้าจอมือถือ หรือตั้งค่าล่วงหน้าในตารางแข่ง
3. **🔗 ฟิก Google Sheets API URL ไว้ในโค้ดได้เลย**:
   * มีตัวแปร `const DEFAULT_API_URL = "..."` ที่ด้านบนสุดของสคริปต์ในไฟล์ `referee.html`, `index.html`, และ `courtside.html`
   * ใส่ URL แค่ครั้งเดียว กรรมการและ OBS ก็เปิดใช้งานได้ทันที ไม่ต้องพิมพ์ URL ซ้ำ
4. **[index.html](file:///g:/My%20Drive/PROGRAM%20%E0%B8%97%E0%B8%B5%E0%B9%88%E0%B9%80%E0%B8%82%E0%B8%B5%E0%B8%A2%E0%B8%99/%E0%B9%82%E0%B8%9B%E0%B8%A3%E0%B9%81%E0%B8%81%E0%B8%A3%E0%B8%A1%20%E0%B8%84%E0%B8%B0%E0%B9%81%E0%B8%99%E0%B8%99%E0%B9%81%E0%B8%82%E0%B9%88%E0%B8%87%E0%B9%81%E0%B8%9A%E0%B8%94%E0%B8%94%E0%B8%96%E0%B9%88%E0%B8%B2%E0%B8%A2%E0%B8%97%E0%B8%AD%E0%B8%94%E0%B8%AA%E0%B8%94/index.html) - OBS Scoreboard Overlay**:
   * สกอร์บอร์ดถ่ายทอดสดสไตล์ TV Broadcast พื้นหลังโปร่งใส
   * แสดงชื่อรายการ, โลโก้, คอร์ท, กติกาแต้ม, ไฟแสดงคนเสิร์ฟ 🏸, สกอร์ 3 เซต, และแถบ Game Point / Deuce / Match Over
5. **[courtside.html](file:///g:/My%20Drive/PROGRAM%20%E0%B8%97%E0%B8%B5%E0%B9%88%E0%B9%80%E0%B8%82%E0%B8%B5%E0%B8%A2%E0%B8%99/%E0%B9%82%E0%B8%9B%E0%B8%A3%E0%B9%81%E0%B8%81%E0%B8%A3%E0%B8%A1%20%E0%B8%84%E0%B8%B0%E0%B9%81%E0%B8%99%E0%B8%99%E0%B9%81%E0%B8%82%E0%B9%88%E0%B8%87%E0%B9%81%E0%B8%9A%E0%B8%94%E0%B8%94%E0%B8%96%E0%B9%88%E0%B8%B2%E0%B8%A2%E0%B8%97%E0%B8%AD%E0%B8%94%E0%B8%AA%E0%B8%94/courtside.html)** - **จอข้างสนาม (Stadium Big Screen)**:
   * สำหรับเปิดบนจอ Smart TV หรือจอ LED ข้างสนาม ตัวเลขคะแนนขนาดใหญ่ยักษ์ เห็นชัดเจนจากระยะไกล
6. **[referee.html](file:///g:/My%20Drive/PROGRAM%20%E0%B8%97%E0%B8%B5%E0%B9%88%E0%B9%80%E0%B8%82%E0%B8%B5%E0%B8%A2%E0%B8%99/%E0%B9%82%E0%B8%9B%E0%B8%A3%E0%B9%81%E0%B8%81%E0%B8%A3%E0%B8%A1%20%E0%B8%84%E0%B8%B0%E0%B9%81%E0%B8%99%E0%B8%99%E0%B9%81%E0%B8%82%E0%B9%88%E0%B8%87%E0%B9%81%E0%B8%9A%E0%B8%94%E0%B8%94%E0%B8%96%E0%B9%88%E0%B8%B2%E0%B8%A2%E0%B8%97%E0%B8%AD%E0%B8%94%E0%B8%AA%E0%B8%94/referee.html)** - **Mobile Referee Controller**:

## 📥 วิธีดึงข้อมูลนักกีฬาจาก Google Sheet ตารางแข่งภายนอก

1. เปิดหน้า [`referee.html`](file:///g:/My%20Drive/PROGRAM%20%E0%B8%97%E0%B8%B5%E0%B9%88%E0%B9%80%E0%B8%82%E0%B8%B5%E0%B8%A2%E0%B8%99/%E0%B9%82%E0%B8%9B%E0%B8%A3%E0%B9%81%E0%B8%81%E0%B8%A3%E0%B8%A1%20%E0%B8%84%E0%B8%B0%E0%B9%81%E0%B8%99%E0%B8%99%E0%B9%81%E0%B8%82%E0%B9%88%E0%B8%87%E0%B9%81%E0%B8%9A%E0%B8%94%E0%B8%94%E0%B8%96%E0%B9%88%E0%B8%B2%E0%B8%A2%E0%B8%97%E0%B8%AD%E0%B8%94%E0%B8%AA%E0%B8%94/referee.html) บนมือถือ
2. ไปที่แท็บ **📅 ตารางแข่ง (Schedule)** > กดปุ่ม **"📥 ดึงข้อมูล Google Sheet"**
3. ใส่ URL ของ Google Sheet (เช่น `https://docs.google.com/spreadsheets/d/1kQLMW_jvr7OKscZ_Pq-leitq-P6n4DCT1vDywM4pADA/...`)
4. ใส่ชื่อแท็บ เช่น `Data`
5. ในช่อง **เลือกคอร์ทที่ต้องการดึง**: ใส่ชื่อคอร์ท เช่น `คอร์ท 9` หรือ `9` หรือ `A1` (หรือเว้นว่างถ้าต้องการดึงทั้งหมด)
6. กดปุ่ม **"🔄 ดึงข้อมูลทันที"**
7. รายชื่อคู่แข่งขันของคอร์ทนั้นๆ จะถูกนำเข้าสู่ตารางแข่งทันที พร้อมให้กรรมการกด **"⚡ นำเข้าขึ้นแข่ง (Load Match)"** ได้เลย!
